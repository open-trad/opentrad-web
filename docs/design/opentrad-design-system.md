# OpenTrad 概念 A 设计系统

## 设计意图

OpenTrad 使用“现代纸张商贸”语言：传统单证的可信、克制和清晰秩序，与现代 Web 工具的效率和反馈结合。界面不使用整图冒充功能，文档缩略图、A4 预览和表单均由真实 HTML/CSS 构成。

批准概念证据保存在 [`opentrad-concept-a.png`](./opentrad-concept-a.png)，仅用于设计追溯，不作为产品界面资产加载。

## 形状与层次

- 卡片使用 7px 小圆角，输入和按钮使用 4px 小圆角。
- 主要边界为 1px 暖灰细线，避免强烈浮层感。
- 纸张使用轻微双层阴影，悬停只提升 4px，不做大幅弹跳。
- 首页纸面纹理由纯 CSS 生成，透明度低，不干扰文字可读性。

## 字体与排版

- 中文正文优先 `PingFang SC`、`Hiragino Sans GB`、`Microsoft YaHei` 等本地系统字体。
- 品牌和大标题优先 Georgia 与系统宋体，形成单证感。
- 不请求远程字体，离线和隐私边界保持稳定。
- 标题以墨蓝、较宽字距建立秩序；辅助文字使用柔和灰蓝。

## 可复用界面模式

- `AppHeader`：品牌、五项导航、语言和移动菜单。
- `.section-container`：统一内容宽度与响应式页边距。
- `.tool-card`：首页核心工具入口。
- `.template-card` 与 `.document-preview`：真实模板卡和 CSS 文档缩略图。
- `.primary-button` / `.secondary-button`：主次操作。
- `.a4-sheet`：报价单实时预览纸面。
- `.conversion-card`：本地和服务器两种能力边界。

## 响应式与动效

- 1240px 为内容最大宽度，1080px、840px、600px 三档调整网格与导航。
- 首页和模板网格从四列依次降为两列和一列。
- 编辑器从三栏降为两段式，再在手机端按步骤、表单、预览纵向排列。
- 所有主容器 `min-width: 0`，页面禁止横向溢出。
- `prefers-reduced-motion: reduce` 下关闭有感过渡和动画。

## 无障碍与交互边界

- 导航、区域、输入与文件选择提供可见或程序化名称。
- 键盘焦点使用明显的蓝色焦点环。
- 服务器增强操作保持禁用，并直接写明需登录和当前不会发起网络请求。
- 信息不只依赖颜色，状态同时有文本和图标。
