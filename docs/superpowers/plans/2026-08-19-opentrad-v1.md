# OpenTrad v1 前端基础 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立可运行、可测试、可部署到 GitHub Pages 的 OpenTrad 现代纸张商贸前端基础。

**Architecture:** 使用 pnpm workspace 管理根工程与 `apps/web`。Web 应用采用 React 19、React Router 与 Vite，页面组件负责业务交互，可复用的壳层和纸张组件维持统一视觉；所有数据均为本地静态示意数据，不接入后端。

**Tech Stack:** Node.js 24、pnpm 10、TypeScript、React 19、Vite、React Router、Lucide React、Vitest、Testing Library、Biome。
